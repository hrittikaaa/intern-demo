API Endpoints

All available REST endpoints exposed by this Spring Boot application.

GET /
Renders the User Management page via Thymeleaf. Accepts optional page and size query params for pagination, and editId to pre-fill the edit form.
▶ Open page
GET /hello
Renders a Thymeleaf greeting page confirming the server is up.
▶ Open /hello
GET /users
Renders a Thymeleaf page showing all users from the database in a table. Supports page and size query params.
▶ View all users
POST /users
Creates a new user. Submitted via the HTML form on the Users page. Requires name and email fields. Validated server-side; redirects back with a flash message.
POST /users/{id}
Updates an existing user. Triggered by the Edit form on the Users page (accessed via /?editId={id}). Requires name and email form fields.
POST /users/{id}/delete
Deletes a user by ID. Triggered by the Delete button on each table row. Redirects back to / with a flash message.
