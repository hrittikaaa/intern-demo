API Endpoints

All available REST endpoints exposed by this Spring Boot application.

GET /hello
Returns a plain "Hello, World!" string. The simplest endpoint to verify the server is up.
GET /users
Fetches and returns a JSON array of all users in the database.
POST /users
Creates a new user. Requires a JSON body with name and email. Validated by the backend.
PUT /users
Updates an existing user. Requires a JSON body with id, name, and email.
DELETE /users
Deletes a user by ID. Requires a JSON body with just the id field.
